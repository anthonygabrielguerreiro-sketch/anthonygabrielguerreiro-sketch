### 👋 Sobre mim

Olá! Sou **Anthony Gabriel**, estudante de Engenharia de Software na Universidade Cidade de São Paulo (Unicid), interessado em tecnologia, desenvolvimento web e análise de dados.

Atualmente, estou desenvolvendo meus conhecimentos em HTML e CSS, aprendendo a estruturar páginas web e a utilizar estilos para criar interfaces. Também tive contato com Power BI, explorando a criação de dashboards e a visualização de dados para facilitar a compreensão das informações.

Busco evoluir constantemente por meio dos estudos, da prática e do desenvolvimento de projetos, construindo uma base sólida para minha carreira na área de tecnologia.
